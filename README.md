# Calculator Web App

A basic calculator built with HTML, CSS and JavaScript, created in 2023 as part
of a beginner Web Development Course.

## Files
- `index.html`: the page structure (buttons and display)
- `style.css`: the layout and styling
- `script.js`: the calculator logic

## How to run
Download or clone the repo and open `index.html` in a web browser.
No installation is needed.

## What I learned
- Building a page layout with HTML
- Styling it with CSS
- Using JavaScript to handle button clicks and calculate results
